1. Calibrate scale

Draw a line along a known reference length (e.g. a scale bar), then enter its real-world length.

If you already know your microscope/camera's calibration (e.g. from a calibration slide or objective spec), enter it directly. This stays applied across images you upload afterward.

2. Detect droplets

Contact angles are derived from detected droplet outlines, so the same circle detection as Size Determination runs first — tune it until the circles match your droplets.

3. Contact angles

For overlapping pairs, assumes each droplet is an undeformed sphere resting tangent to the substrate (so a droplet's center height above the substrate equals its own radius). See the README on GitHub for the full model and its limitations.
